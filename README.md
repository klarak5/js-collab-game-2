# Ucieczka z serwerowni

Dostepne komendy: gra.start(), gra.pomoc(), gra.status(), gra.mapa(), gra.rozejrzyj(), gra.wykonaj("lewo"), gra.wykonaj("prawo"), gra.wykonaj("karta"), gra.wykonaj("bezpiecznik"), gra.wykonaj("napraw"), gra.wykonaj("otworz"), gra.wykonaj("klucz"), gra.wykonaj("wyjdz")

Aby wygrac musisz:

* zebrac klucz z recepcji,
* zebrac bezpiecznik z magazynu,
* naprawic zasilanie w serwerowni,
* otworzyć biuro,
* zebrac karte z biura,
* oraz wyjsc.

Kazdy udany ruch i wykonana akcja kosztuja dokladnie 1 energie. Ogladanie mapy, pomocy, stanu, oraz rozgladanie sie sa bezplatne. Jesli twoja energia spadnie do zera, przegrywasz. Jesli uda ci sie wyjsc z serwerowni, wygrywasz.
